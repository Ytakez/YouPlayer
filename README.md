# YouPlayer

Локальный музыкальный плеер для Android от Ytakez. Kotlin, Jetpack Compose, Material 3 Expressive и Media3.

## Возможности

- автоматический поиск всей музыки на устройстве (MediaStore), без ручного выбора папок и файлов;
- MP3, M4A, AAC, FLAC, OGG, Opus, WAV и WMA (фактическая поддержка зависит от декодеров устройства);
- обложки и метаданные, поиск по библиотеке;
- фоновое воспроизведение и системное музыкальное уведомление;
- умный микс с автоматически пополняемой очередью;
- рекомендации по исполнителю, альбому, жанру, лайкам, завершённым прослушиваниям и пропускам;
- мини-плеер и полноэкранный плеер в стиле Material 3 Expressive: кнопка play меняет форму, волнистая полоса перемотки, переключатели повтора и случайного порядка;
- динамические цвета Material You на Android 12+ и тёмная тема;
- **настройки** (шестерёнка в углу любого экрана): тема, палитры и свой оттенок, AMOLED-чёрный, скругления, размер текста, формы обложки, волна перемотки, сортировка и плотность списка, длина микса, таймер сна;
- листание песен свайпом: в полноэкранном плеере, в мини-плеере и между вкладками;
- анимации Material 3 Expressive: пружинящие переходы, превращение кнопок, вращающаяся обложка, эквалайзер, плавная смена цветов темы;
- история хранится только на устройстве.

## Установка

Открой APK на телефоне с Android 8.0 или новее и разреши установку из выбранного источника. При первом запуске разреши доступ к музыке и уведомления — приложение само найдёт все песни на телефоне.

## Сборка

Нужны JDK 17 и Android SDK 35:

```bash
./gradlew testDebugUnitTest assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Для сборки без компьютера загрузи проект в GitHub и запусти workflow **Собрать YouPlayer APK** на вкладке Actions. APK появится в артефактах workflow.

## Приватность

Приложение не использует аккаунты, аналитику, сервер или рекламу. Музыка и история прослушиваний остаются на телефоне. Приложение читает только аудиофайлы на устройстве (разрешение «Музыка и аудио») и никуда их не отправляет.
